## Информация команды

**НарядAI — команда ByteX**

Проект для кейса №1 АО «Костанайские Минералы» на QOSTANAI AI INDUSTRY HACKATHON 2026.

**Задача:** перевести выдачу и выполнение производственных нарядов в цифровой процесс. Мастер назначает работу, сотрудник фиксирует выполнение и отправляет отчёт, ИИ помогает проверить сведения, мастер принимает окончательное решение.

**Технологии**

| Часть проекта | Реализация |
|---|---|
| Android-приложение | Flutter / Dart; Kotlin для интеграции диктовки |
| Веб-версия | HTML, CSS, JavaScript, PWA |
| Сервер | Python, FastAPI, Uvicorn |
| Общая база данных | PostgreSQL; SQLite для локальных проверок |
| Хранение фотографий | Адаптер Supabase Storage |
| Версия для ПК | Python / PySide6 |
| Сборка и проверки | GitHub Actions, Flutter Test, Python unittest |

**ИИ и модели**

- **Qwen3.5-9B** — выбранная командой модель для анализа отчётов и изображений. Интеграция реализована через AnythingLLM и Ollama. Модель поддерживает текст и изображения. [Официальная карточка](https://huggingface.co/Qwen/Qwen3.5-9B).
- **Vosk, vosk-model-small-ru-0.22** — локальное распознавание русской речи в Android. Сотрудник проверяет полученный текст перед отправкой отчёта.
- **AnythingLLM** управляет рабочими пространствами и инструкциями; **Ollama** запускает модель на компьютере.
- **OpenAI Codex** использовался при разработке кода, интерфейса, интеграции, тестов и документации.

Сроки, рейтинги, расход материалов и простои рассчитывает сервер по данным БД. Модель выполняет смысловой анализ и объясняет замечания.

**Реализованный функционал**

Авторизация по ролям; создание и назначение нарядов; принятие, очередь, отказ, начало и приостановка работы; график и загрузка сотрудников; отчёты с материалами и фотографиями; голосовой ввод; предварительная проверка ИИ; приёмка или доработка мастером; статистика, рейтинг и история действий.

Android сохраняет черновики без сети. Администратор открывает мобильную веб-панель.

**Данные и проверка**

Подготовлен демонстрационный архив приложения с **608 нарядами за три месяца**. Отдельно создан корпус для развития ИИ: **500 отчётов, 64 единицы оборудования и четыре заложенные закономерности**. Данные синтетические.

Android APK 1.0.1 опубликован, автоматическая сборка и 11 Flutter-тестов прошли. Отдельно проверен серверный цикл от создания наряда до приёмки отчёта.

**Ожидаемый эффект:** прозрачная загрузка персонала, меньше потерянных поручений, подтверждение выполненных работ и накопление истории для планирования ремонтов. Экономический эффект предстоит измерить на пилоте.
